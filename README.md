# MARKO – Universal Media Downloader

**كل محتواك.. في مكان واحد** — موقع حقيقي (مش Prototype) لتحميل الفيديوهات والصوتيات من الروابط المدعومة، بواجهة عربية RTL داكنة بدرجات الأخضر الزمردي، وبدون أي إعلانات نهائيًا.

## اللي بيعمله فعلًا
- تحليل الرابط تلقائيًا وعرض الصورة المصغرة والاسم والمدة و**الجودات الحقيقية المتاحة بس**.
- اختيار بسيط بلغة الناس: **فيديو** (تشوفه وتسمعه) أو **صوت بس** (تسمعه من غير صورة).
- Backend حقيقي: FastAPI + yt-dlp + FFmpeg، طابور Jobs و Workers.
- **نسبة تحميل حقيقية** عبر Server-Sent Events: نسبة %، بايتات نزلت/الكل، سرعة، وقت متبقي، حالة — كلها من تقدم التحميل الفعلي في الـ Backend، مفيش أرقام متخمنة.
- بعد الاكتمال: اسم الملف وحجمه + زر تنزيل على الجهاز (السيرفر بيبعت الملف بـ `Content-Disposition: attachment` وبيدعم HTTP Range) + نسخ رابط التحميل + تحميل ملف آخر.
- دعم لينكات الملفات المباشرة (MP4/MP3/ZIP/PDF/APK/صور...) بتحميل Streaming على دفعات (Chunked) — الملف مش بيتحمل كله في الرام.
- رسائل خطأ عربية واضحة: رابط غير صالح / موقع غير مدعوم / محتوى خاص أو محتاج تسجيل دخول.
- **مفيش أي تجاوز** لحماية المنصات أو DRM أو تسجيل الدخول أو حماية البوتات. لو منصة حجبت التحميل، الموقع بيقول كده بصراحة.

## الأمان والأداء
- حماية SSRF: رفض أي رابط بيؤدي لعناوين داخلية/خاصة (private / loopback / link-local / reserved).
- Rate Limiting عادل لكل IP، وحد لعدد التحميلات المتزامنة (Queue + Workers).
- حد أقصى لحجم الملف قابل للتعديل من متغير بيئة.
- الملفات المؤقتة بتتمسح تلقائيًا بعد فترة الاحتفاظ.
- مفيش مفاتيح API في الواجهة الأمامية أصلًا (الموقع مش بيستخدم مفاتيح).

## التشغيل محليًا
متطلبات: Python 3.11+ و FFmpeg مثبّت على الجهاز.

```bash
cd marko-downloader
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
افتح: http://localhost:8000

## التشغيل بـ Docker (الأسهل للنشر)
```bash
docker build -t marko .
docker run -p 8000:8000 \
  -e MAX_FILE_SIZE_MB=2048 -e MAX_CONCURRENT_DOWNLOADS=2 -e FILE_RETENTION_MINUTES=60 \
  marko
```

## النشر على Render (مجاني — خطوة بخطوة)
المشروع مجهّز بـ `render.yaml` (Blueprint) وبـ Dockerfile بيشتغل على البورت اللي Render بيحقنه (`PORT`) تلقائيًا.

1. ارفع كود المشروع على Git (GitHub مثلًا): `git init && git add . && git commit -m "MARKO" && git push`.
2. من لوحة Render: **New → Blueprint** واختار الريبو — Render هيقرأ `render.yaml` لوحده ويجهّز خدمة ويب اسمها `marko` بخطة **Free** وبيئة **Docker** (أو بديلًا: **New → Web Service** واختار الريبو وDocker وخطة Free يدويًا).
3. متغيرات البيئة جاهزة في الـ Blueprint: `MAX_CONCURRENT_DOWNLOADS=2` (مناسب لرامات الخطة المجانية 512MB)، `FILE_RETENTION_MINUTES=60`، `MAX_FILE_SIZE_MB=2048` — ومفيش متغير `PORT` (Render بيحقنه) ومفيش قرص دائم (مش محتاجينه؛ الملفات مؤقتة).
4. دوس **Apply / Create** واستنى أول Build يخلص. فحص الصحة على `/healthz`.
5. الرابط العام هيبقى شكله: `https://marko.onrender.com` (أو اسم قريب لو الاسم محجوز).
6. تنبيهات الخطة المجانية: الخدمة **بتنام بعد ~15 دقيقة خمول** وأول زيارة بعدها بتاخد ~دقيقة على ما تصحى، والقرص مؤقت فالملفات الجاهزة بتضيع مع إعادة التشغيل (عادي — هي أصلًا مؤقتة وبتنتهي بعد 60 دقيقة).

## النشر على رابط عام (لازم حساب استضافة بتاعك)
المشروع جاهز كخدمة واحدة (Dockerfile). خطوات عامة:
- **Render / Railway:** اربط مستودع GitHub، اختار Docker، حط متغيرات البيئة اللي تحت، وانشر. هيديك رابط عام `https://...`.
- **VPS (Ubuntu):** ثبّت Docker، ابنِ وشغّل الأوامر اللي فوق، وحط Nginx/Caddy قدامها بـ HTTPS (Let's Encrypt)، وافتح البورت.
- ملحوظة: الاستضافات المجانية بتنام بعد الخمول ومساحة قرصها صغيرة — للفيديوهات الكبيرة الأفضل خطة مدفوعة صغيرة أو VPS بقرص كفاية (شوف TEST-REPORT.md للحدود المقاسة).

> النشر الفعلي على أي مزوّد محتاج حساب المزوّد وموافقتك — الكود جاهز، وخطوة النشر دي بتتعمل بحسابك.

## متغيرات البيئة
| المتغير | الافتراضي | المعنى |
|---|---|---|
| `PORT` | 8000 | بورت السيرفر |
| `MAX_FILE_SIZE_MB` | 2048 | أقصى حجم ملف بالميجابايت |
| `MAX_CONCURRENT_DOWNLOADS` | 2 | التحميلات المتزامنة |
| `FILE_RETENTION_MINUTES` | 60 | مدة الاحتفاظ بالملف الجاهز قبل مسحه |
| `DATA_DIR` | ./data/tmp | مكان التخزين المؤقت |

## متطلبات السيرفر
- CPU: 1–2 كور على الأقل (دمج الصوت والصورة بـ FFmpeg بيستخدم CPU).
- RAM: 1 GB على الأقل (التحميل Streaming فمش بياكل رام على قد حجم الملف).
- قرص: على الأقل ضعف أكبر ملف متوقع × عدد التحميلات المتزامنة (ملفات مؤقتة + ناتج مدموج).
- FFmpeg مثبّت (موجود جوه صورة Docker جاهز).
